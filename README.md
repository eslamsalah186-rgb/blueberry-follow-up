# Blueberry Field Operations Dashboard

A comprehensive monitoring and management system for blueberry farming operations, built with modern web technologies.

## 🌟 Overview

This dashboard provides real-time monitoring and data management for blueberry cultivation, featuring modules for growth tracking, climate monitoring, irrigation management, and integrated pest management (IPM).

## 📋 Features

### Core Modules
- **Farm Dashboard** - Overview of all farm operations and key metrics
- **Data Registration** - Input and management of farm data
- **Growth & Census** - Plant growth monitoring and population tracking
- **Harvest & Quality** - Harvest management and quality control
- **Climate Monitoring** - Weather data and environmental controls
- **Irrigation & Fertilization** - Water and nutrient management
- **Integrated Pest Management (IPM)** - Pest control and monitoring
- **Historical Records** - Data archives and trend analysis

## 🛠️ Technology Stack

- **Frontend**: Pure HTML5, CSS3, JavaScript
- **Charts**: Chart.js for data visualization
- **Fonts**: Google Fonts (DM Serif Display, DM Mono, IBM Plex Sans Arabic)
- **Language**: Arabic (RTL support)
- **Design**: Organic Brutalism aesthetic with warm color palette

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/eslamsalah186-rgb/blueberry-follow-up.git
   cd blueberry-follow-up
   ```

2. **Open the dashboard**
   - Open `index.html` in your web browser
   - The main dashboard will load with navigation to all modules

3. **Navigate between modules**
   - Use the sidebar navigation to access different monitoring sections
   - Each module opens as a separate page within the dashboard

## 🎨 Design Philosophy

The dashboard follows an "Organic Brutalism" design approach:
- Warm cream color palette (#f0ede6, #e8e4db)
- Forest green accents for data visualization
- Berry purple for active navigation states
- Clean typography with serif headings and monospace data
- RTL (Right-to-Left) layout for Arabic language support

## 📊 Data Visualization

All modules include interactive charts and graphs powered by Chart.js:
- Real-time data displays
- Historical trend analysis
- Performance metrics
- Environmental monitoring graphs

## 🌍 Language Support

- **Bilingual Interface**: Arabic (العربية) and English
- Dynamic language switching with toggle button (EN/عر)
- RTL/LTR text direction support
- Fully localized interface elements and data labels
- Default language: Arabic
